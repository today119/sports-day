🔥 Firebase 연결 설정

처음 한 번만 설정하면 이후엔 바로 열립니다.
설정값은 이 기기 브라우저에 저장됩니다.

1 Firebase 프로젝트 만들기
console.firebase.google.com 접속
→ "프로젝트 추가" → 이름 입력 → Google Analytics 비활성화 → 완료
2 Realtime Database 생성
왼쪽 메뉴 → "빌드" → "Realtime Database" → "데이터베이스 만들기"
→ 위치 asia-southeast1 선택 → "테스트 모드"로 시작 → 완료
3 앱 등록 후 설정 코드 복사
프로젝트 홈 → ⚙️ → "프로젝트 설정" → 하단 "내 앱" → 웹 앱 </> 클릭
→ 앱 등록 → firebaseConfig = {{ ... }} 안의 내용 전체 복사
올바른 JSON 형식이 아닙니다. { } 안의 내용을 그대로 붙여넣어 주세요.
설정값은 브라우저 localStorage에만 저장됩니다
